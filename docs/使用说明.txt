QQ 音乐批量解码工具 1.0
Windows 10 / 11 64 位便携版

快速开始
1. 打开桌面版 QQ 音乐，登录能完整播放这些歌曲的账号。
2. 双击构建生成的 artifacts\QQBatchDecoder.exe，无需安装 Python。
3. 点击“添加文件夹”或“添加歌曲”，也可拖放文件或文件夹。
4. 选择保存位置，点击“开始解码”。
5. 完成后点击“打开输出目录”；双击已完成的列表项也可定位文件。

支持的格式
带 musicex V1 文件尾的新版本 QQ 音乐文件：
  .mflac → .flac
  .mgg   → .ogg
  .mmp4  → .m4a
保留原来的音频编码、采样率、位深和已有标签，不额外转码。
不支持 NCM、KGM、旧版 QMC / QTag / STag，以及尚未下载完成的文件。
目前已用本机 QQ 音乐 22.7.1 的两首 .mflac 实测，包括 24-bit / 192 kHz 母带。

批量处理
默认包含子文件夹，并在输出位置保留各输入文件夹内部的目录结构。
源文件始终保留；同名输出自动添加 (2)、(3) 等编号，不覆盖已有文件。
某首失败会继续处理下一首，失败原因显示在该行，并写入本次 JSON 报告。
点击“停止”会取消当前任务，并清理本次尚未完成的临时输出。
再次处理相同文件时，会根据源文件大小、修改时间及输出状态跳过已完成歌曲。
跳过记录保存在输出目录的 .qqdecode-history.json，不包含登录信息或解密密钥。
删除或修改输出后，再次运行会重新解码。请保留处理记录以便断点续跑。

完整性校验
推荐保持“完整性校验”勾选。
程序会查找旁边的 ffmpeg.exe、PATH 中的 FFmpeg，以及本机剪映安装目录中的 FFmpeg。
如果已安装可用的 FFmpeg，工具会尝试自动识别。
FLAC 会完整解码并对照文件内的音频 MD5；其他格式会完整解码检查。
校验失败的临时输出会被清理，不作为成功歌曲保存。
本工具未捆绑 FFmpeg。换电脑后可点击“选择校验程序”指定 ffmpeg.exe。
也可取消完整性校验，此时只验证音频文件头，无法确认整首音频完全正确。

QQ 音乐登录与网络
每批次在本机读取正在运行的 QQ 音乐进程中与本次解码有关的会话信息，
仅向 QQ 音乐官方服务请求对应歌曲的密钥；音频文件不上传。
会话信息及解密密钥只保存在运行时内存，不写入报告或其他磁盘文件。
首次获取每首歌的密钥需要联网，且当前 QQ 音乐账号需有对应访问权限。
工具不提供登录、购买、音乐下载功能。
QQ 音乐客户端或接口以后变化时，可能需要更新工具。

常见问题
“请先打开 QQ 音乐”：启动桌面客户端并完成登录，再点击开始。
“无法读取 QQ 音乐”：让工具和 QQ 音乐以相同权限级别运行。
“未返回可用密钥”：先确认当前账号可完整播放此歌，再尝试重新登录。
“无损校验不一致”：重新下载该歌曲后重试；原文件和已有输出不会被覆盖。
旧格式或其他平台的加密文件会报告不支持。

命令行（可选）
QQBatchDecoder.exe --cli "D:\歌曲" --output "D:\已解码"
QQBatchDecoder.exe --cli "D:\歌曲" --output "D:\已解码" --ffmpeg "D:\工具\ffmpeg.exe"
QQBatchDecoder.exe --cli "D:\歌曲" --output "D:\已解码" --no-verify
可加 --no-recursive 关闭子文件夹扫描。
可加 --report "D:\本次报告.json" 另外保存一份 JSON 报告。
退出码：0=全部成功或已跳过；1=有失败或停止；2=参数或启动错误。

开发与测试
source 中包含 C# 源码和参考测试向量。
运行根目录的 Build.ps1 可使用 Windows 自带 .NET Framework 编译器重新生成程序。
编译及运行程序不需要 Node.js、Python 或其他第三方运行时。
程序要求 .NET Framework 4.8（Windows 10 / 11 通常已包含）。
QMC2 核心算法基于 QM Unlock，遵循 MIT 许可，详见 THIRD-PARTY-NOTICES.txt。
